# 单元格内容测试（普通表）

| 场景 | 单元格内容 | 说明 |
|---|---|---|
| `<br>` 换行 | 第一行<br>第二行 | 最常用写法 |
| `<br><br>` 空行 | A<br><br>B | 双换行 |
| `<br/>` 自闭合 | 甲<br/>乙 | XHTML 写法 |
| 转义竖线 | a \| b \| c | 单元格里的管道 |
| 行内代码 | `x \| y` | 代码里的竖线 |
| 链接 | [示例](https://example.com) | 普通链接 |
| 行内公式 | $a^2+b^2=c^2$ | KaTeX |
| 空单元格 |  | 中间是空的 |
| 长文本+换行 | 这是很长的一段说明文字，用来验证折行与手动换行叠加时的排版是否正常<br>这是手动换行的第二段 | 混合 |
