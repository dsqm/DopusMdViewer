# 装机验收清单（md5 95e2e7f7）

当前装进 Opus 的是 `95e2e7f7`，对应提交 `8da07f2`（历史重写后的 hash）。**重启 Opus 后**再开始；DLL 与 `web\` 必须是
同一版本（帧格式变了，只换一个会画出错位的 mark）。

样本：`10/11-*.md` 已入库；带「生成」标记的两份跑一次脚本：

```
python samples\manual-test\gen-search.py     → %TEMP%\mdvsearch\  (big-fence-hits.md / mid-blocks.md)
```

`%TEMP%\mdvbig\` 里已有 `big1g.md`（1 GB）、`giant.md`（210 MB）。

## 一、正则（打开 `10-search-regex.md`）

| # | 操作 | 预期 |
|---|---|---|
| 1 | 开 `.*`，搜 `\d{4}-\d{2}-\d{2}` | **10 处**，计数显示 10。列表/表格/行内代码/围栏里的都算；被换行切断的那条不算 |
| 2 | 搜 `^## ` | **4 处**（`###` 那行不算） |
| 3 | 搜 `Error`（Aa 关）→ 再点 Aa | 4 处 → **1 处**（只有首字母大写那行） |
| 4 | 搜 `[a-` | 提示 **「正则无效：missing terminating ] for character class」**，不是 0 结果 |
| 5 | 关 `.*` 再搜 `^## ` | **无结果**（按字面找，文件里没有这串字符） |
| 6 | `.*` 打开时看 W 按钮 | W 变灰、点不动（正则下整词禁用） |

## 已知取舍，不算失败

- 第 9 条 `中文abc` 不命中：整词是 ASCII 词边界。
- 无 BOM 且纯 CJK 的 UTF-16 文件：判不出来（没有任何 `0x00` 可依），S5 的手动覆盖是逃生口。
- 巨型块段被回收后 mark 消失。
